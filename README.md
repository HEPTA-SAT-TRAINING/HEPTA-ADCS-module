# HEPTA ADCS Module

Shared attitude determination, reaction-wheel control, and radio command
sources for the HEPTA-SAT PD control sketch.

## Layout

- `adcs/`: attitude control and angular estimation
- `command/`: serial/radio commands and telemetry output

This repository is used as the `src/adcs_module` Git submodule of the main
`Labxx_PD_control` repository.
